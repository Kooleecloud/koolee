# Driver UI kit

Native twins of `packages/ui` — same names, same props where the platform allows, same token classes (NativeWind on `tailwind.tokens.js`, generated from `packages/ui/styles/theme.css`). Always use this kit's `Text`, never react-native's, so the Inter/Sora faces apply. Every tappable element takes a `testID`; the simulator flows drive the app by them.

| Component                                                               | Web twin                                             | Notes                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Text` (`face`, `weight`)                                               | plain elements + `font-display` / `font-medium`      | Weight is a prop, not a class: Tailwind weights do not switch font families on native.                                                                                                                                                                              |
| `Button` (`variant`, `size`, `loading`, `icon`)                         | `components/button.tsx`                              | No `asChild` / `link` variant; pass `onPress`. `h-11` default (web `h-9`) for a thumb target.                                                                                                                                                                       |
| `Card` / `CardHeader` / `CardTitle` / `CardDescription` / `CardContent` | `components/card.tsx`                                | `p-4` padding (web `p-6`); lift shadow via `style`, since NativeWind has no `shadow-lift`.                                                                                                                                                                          |
| `Badge` (`variant`)                                                     | `components/badge.tsx`                               | Same six variants.                                                                                                                                                                                                                                                  |
| `Input` / `Label`                                                       | `components/input.tsx`, `components/label.tsx`       | `h-11` (web `h-9`).                                                                                                                                                                                                                                                 |
| `FormMessage` (`variant`)                                               | `components/form-message.tsx`                        | `error` announces as an alert. No scroll-into-view on mount.                                                                                                                                                                                                        |
| `Screen`                                                                | `components/shell/agent-main.tsx` (`ContentColumn`)  | Safe-area scroll column, `px-4 pt-5 gap-4`, pull-to-refresh replaces `router.refresh()`.                                                                                                                                                                            |
| `Avatar` (`name`, `src`, `size`)                                        | `components/avatar.tsx`                              | Same `TINTS` + hash (`avatar-fallback.ts`, unit-tested); `Image` `onError` falls back to initials; lucide `User` when there is no name. `alt` as on the web: defaults to `name`; pass `""` when the name is written beside it, and the avatar leaves the a11y tree. |
| `EmptyState` (`icon`, `title`, `description`, `action`)                 | `components/empty-state.tsx`                         | Pass the icon at `size={32}` with the muted colour (`#58687e`); the web sizes it with `[&_svg]:size-8`.                                                                                                                                                             |
| `Skeleton` / `PageSkeleton` (`cards`)                                   | `components/skeleton.tsx`                            | `animate-pulse` as an `Animated` opacity loop (1 → 0.5 → 1, 2 s).                                                                                                                                                                                                   |
| `Select` (`value`, `onValueChange`, `items`, `placeholder`, `testID`)   | `components/select.tsx` (native `<select>`)          | Trigger has `Input` metrics; opens a bottom-sheet `Modal`. Rows are `${testID}-option-${value}`, the scrim `${testID}-scrim`.                                                                                                                                       |
| `SegmentedControl` (`items`, `value`, `onChange`, `label`)              | `components/segmented-control.tsx`                   | Buttons only (no `href` / `linkComponent`); tabs are `${testID}-${value}`, default prefix `segment`.                                                                                                                                                                |
| `StageDot` (`state`)                                                    | `components/stage-dot.tsx`                           | `current` pings with an `Animated` halo; the `ring-4` is an absolute `-inset-1` view so the dot stays 12 px.                                                                                                                                                        |
| `CustodyTimeline` (`items`, `emptyMessage`)                             | `components/custody-timeline.tsx`                    | Vertical only. No `badge`, `actor`, `icon`, `photoAsButton`; `metaDateTime` accepted but not rendered (no `<time>`). Items are `custody-${id}`, photos `custody-${id}-photo`.                                                                                       |
| `BookingRef` (`value`)                                                  | `apps/agent/src/components/job/booking-ref.tsx`      | `bg-tag-400` + `text-navy-800` (5.43:1). Mono, semibold.                                                                                                                                                                                                            |
| `BackLink` (`onPress`, `children`)                                      | `components/back-link.tsx`                           | Ghost `sm` button with `ChevronLeft`; `onPress` instead of `href`. Default `testID="back-link"`.                                                                                                                                                                    |
| `ImageLightbox` (`src`, `alt`, `title`, `description`, `className`)     | `components/image-lightbox.tsx`                      | Thumbnail `Pressable` → full-screen `Modal`, image `contain`, outline **Close** (`${testID}-close`). Thumbnail trigger only (no `"button"` trigger).                                                                                                                |
| `ToastProvider` / `useToast()` / `Toaster`                              | `components/sonner.tsx` (`toast.success/error/info`) | Top-centre, auto-dismiss 3.5 s, tap to dismiss, three visible. `ToastProvider` mounts the host itself (in `app/_layout.tsx`); cards are `toast-${kind}`.                                                                                                            |

Not ported on purpose: `Popover` (the shift pill became `ShiftCard`), `PageHeader` (screens set their own `text-3xl` title), `AppHeader`/`KooleeLogo` (tabs replace the header), `PushEnableCard` (native push instead of web push), `AvatarUploader` (camera + Storage upload lives in the account screen).
